## Правила

1. Один пост в день на канал, не пачкой (правило введено 30.10.2026).
2. Каждый пост: изображение-обложка, жирный заголовок, воздух между блоками,
   финальная цитата-призыв со ссылкой на AI.
3. Минимум одна прямая ссылка на конкретный пост основного канала.
4. Фразы призыва не повторяются — реестр `channels/<slug>/cta-phrases.json`.
5. После публикации: GET-проверка, обновление архива, коммит, пуш.
6. Изображения — из архива AI (`local/images/ainow`, `tools/pick_image.py`), свои карточки не рисуются.
