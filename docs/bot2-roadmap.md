# Дорожная карта бота «Кросс Автопостинг» (@se14808890_1_bot)

Бот создан 13.11.2026, модерация пройдена 14.11.2026. Название: «Кросс
Автопостинг», описание: «Кросспостинг и автопостинг для авторов: перенос
постов из Telegram, отложенная публикация, вычитка текста. Ведение каналов
MAX.»

**Назначение** (решение владельца 14.11): сервисный бот для **пользовательских
каналов** — помогать другим авторам вести каналы MAX. Наши собственные каналы
ведёт первый бот (`@se14808890_bot`, ключи ainow/na100/catden/zabava в
`local/tokens.json`) — второй бот к ним не подключается.

Развиваем **поэтапно**. Ниже roadmap; сроки, кроме этапа 1, не назначены
(«без срочно»).

## Технические заметки (по мере обсуждения)

- Токен бота: пока не передан; план — владелец сохраняет в
  `local/bot2-token.txt`, скрипт `local/bot2_register.py` проверяет (`GET /me`),
  пишет ключ `bot2` в `local/tokens.json` и удаляет файл.
- Слушатель обновлений: `GET /updates` (long poll) — резидентный скрипт или
  задача Планировщика с коротким интервалом.
- Лимиты Bot API: 2 сообщения/сек на чат, 30 rps на API в целом.
- Изменение описания/названия бота = повторная модерация: новые функции
  (анализ канала, SEO) могут потребовать обновить описание — учесть при
  переходе к этапам 3–4.
- Права в чужих каналах: запрашиваем минимально необходимое (писать посты;
  редактировать — только для сценариев правок).
