# Анализ статистики каналов (ainow + zabava)

Выводы агента по утренним снимкам (07:00 МСК). Сырые данные — `local/stats/*.json`
и `local/stats-report-<канал>.txt`, они в git не попадают (`local/` в gitignore),
поэтому этот файл — постоянная запись выводов. Новая дата — новая секция сверху.

## 10.11.2026 — первый анализ

База: снимок ainow от 09.11 17:20 (127 подписчиков) и от 10.11 07:00;
для zabava это первый снимок — дальше от него считается динамика.

### ainow (AI): 128 подписчиков, 31 пост

| Показатель | Значение |
|---|---|
| Подписчики | 127 → 128 (+1 за 13.7 ч) |
| Сумма просмотров | 4109 |
| Медиана / среднее / max | 92 / 133 / 795 |
| Прирост за ночь | все 31 поста получили ≥1 просмотра |

Выводы:

1. **Длинный хвост работает.** За одну ночь ни один пост не остался без
   просмотров — каталог/рекомендации MAX равномерно подвозят читателей к старым
   материалам. Старые посты (июль–август, 9 шт. из 31) дают 58% всех просмотров
   (2392 из 4109).
2. **Свежий пост заходит лучше обычного.** «Как подключить бесплатный ИИ к боту
   из России: 5 путей» (09.11) — лучший прирост ночи: +8 (всего 38). Тема
   «бесплатно + из России» снова в топе движения.
3. **Абсолютный лидер** — пост 16.08 «Бесплатные браузерные AI-агенты: …»
   (795 просмотров, в 6 раз выше медианы). Обе темы-лидера — про бесплатные
   инструменты, доступные из России.
4. **Частота выросла — медиана упала.** По месяцам: июль 171, август 302,
   сентябрь 131, октябрь 64 (14 постов), ноябрь 46. Но сумма за октябрь (1103) —
   вторая после августа: рост частоты компенсирует падение среднего охвата.
   Это нормальный обмен: чаще публиковать → ниже охват одного поста, выше суммарный.

### zabava (Забавное): 14 подписчиков, 114 сообщений (выборка — 100 постов)

| Показатель | Значение |
|---|---|
| Сумма просмотров | 5207 |
| Медиана / среднее / max | 43 / 52 / 128 |
| Видео-постов | 96 из 100 (медиана 43 против 25.5 у не-видео) |

Выводы:

1. **Охват втрое больше числа подписчиков.** Медиана 43 просмотра при 14
   подписчиках: зрителей приносит не подписная база, а рекомендации и каталог
   MAX. Канал «находят», а не «на него подписаны» — значит, главный рычаг роста
   это конверсия зрителя в подписчика, то есть призыв в каждом посте.
2. **Видео — формат канала.** Всё топ-5 — видео с животными и простой эмоцией:
   «Панда и баскетбольные щиты» (128), «Мама с медвежатами на рыбалке» (120),
   «Тюлень» (108), «Красная панда» (103). Видео собирают медиану 43 против 25.5
   у фото — рандом-план, который переиздаёт старые видео с призывом, выбран верно.
3. **Свежие посты имеют низкие цифры — это эффект возраста, а не интереса.**
   Посты с 01.11: медиана 8.5 против 45.5 у старых, но старым было недели на
   накопление. Честное сравнение — через 1–2 недели снимков.
4. Пост 18.09 с призывом в тексте набрал 123 (2-е место за всю выборку) —
   призыв не мешает охвату.
