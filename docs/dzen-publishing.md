# Публикация в Дзен: что реально работает

## Коротко

У Дзена **нет открытого API** для публикации материалов в канал. Единственный
машинный путь — **RSS-трансляция**: канал привязывается к вашему сайту, робот
Дзена забирает ленту и сам создаёт публикации. Всё остальное (постить в Студии)
— только руками или браузерной автоматизацией.

Проверено по справке Дзена 31.10.2026:
— `https://dzen.ru/help/ru/website/site-to-channel.html` (объединение сайта и канала);
— `https://dzen.ru/help/ru/website/rss-modify.html` (разметка ленты).

## Как это устроено

1. В Студии: **Настройки → Свой сайт** → добавить домен → подтвердить права
   (HTML-файл в корне сайта или метатег на главной).
2. Там же: **Настроить трансляцию материалов сайта в Дзен** → указать URL ленты
   → отправить на проверку.
3. После одобрения робот обходит ленту каждые 2–5 минут и публикует новые
   материалы в канале автоматически.

## Требования Дзена (сжато)

- к каналу можно привязать сайт только после **10 подписчиков**;
- лента — RSS 2.0: `title`, `link`, `guid`, `pubDate` (RFC 822),
  `content:encoded` с HTML;
- при первой отправке — **минимум 10 материалов**, на сайте — **не менее 3
  публикаций за последний месяц**;
- обложка — `enclosure`, ширина картинки **≥ 700 px** (JPEG/PNG/GIF);
- URL материалов — ЧПУ, без UTM и параметров, каждый открывает одну статью;
- `contentType` = `blogs_only` — статья только для канала (текст может
  отличаться от сайта);
- `robots.txt` не должен запрещать ленту;
- файл ленты ≤ 10 МБ и отдаётся за ≤ 10 секунд;
- **не более 3 проверок ленты в год** — попытки бережём, отправляем только
  готовую ленту.

## Что уже сделано

`tools/dzen_build.py` собирает пакет для выкладки:

```
python tools/dzen_build.py --channel ainow --base https://0s3.ru/dzen
```

Результат — папка `dzen/`:

- `index.html` — список материалов;
- `<slug>.html` — страницы материалов (ЧПУ, без параметров);
- `rss.xml` — лента RSS 2.0 с `content:encoded`, `enclosure` и `format-article`.

Сейчас в ленте 16 материалов канала AI (у всех есть обложка ≥ 700 px),
публикации с видео пропускаются — у них нет картинки для карточки.

## Как выложить

**Вариант A — scp/ssh (автоматически).** Нужны хост, логин и пароль/ключ
хостинга 0s3.ru. Заливаем в `~/0s3/public_html/dzen/`.

**Вариант B — файловый менеджер панели.** Готовый архив
`local/dzen-upload.zip` распаковать в `public_html/dzen/`.

**Вариант C — GitHub Pages.** Публикуем папку `dzen/` в ветку `gh-pages` и
включаем Pages в настройках репозитория. Домен будет `*.github.io` — Дзен может
отнестись к такому сайту строже при проверке.

## Шаги в Студии (делает владелец канала)

1. Убедиться, что у канала ≥ 10 подписчиков.
2. Настройки → Свой сайт → добавить домен → подтвердить (положить выданный
   Дзеном HTML-файл в корень сайта или вставить метатег).
3. Настроить трансляцию → указать `https://0s3.ru/dzen/rss.xml` → отправить
   на проверку.
4. После одобрения новые материалы из ленты появляются в канале сами.

## Ограничения, о которых стоит помнить

- править материал через RSS можно 7 дней после первой загрузки; позже —
  только вручную в Студии;
- если править публикацию в Студии, последующие обновления по RSS для неё уже
  не применятся;
- API для статистики у Дзена тоже нет — цифры только в Студии;
- лимит проверок ленты — 3 в год.
