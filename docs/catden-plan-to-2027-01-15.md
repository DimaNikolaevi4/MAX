## Операционный регламент

### Публикация (хостинг)
- Слот **20:00 МСК** — настроить на хостинге (`post_cron.php`, Beget). Конвенция: имя файла = дата, посты `approved` с датой ≤ сегодня.
- Праздничные черновики публикуются только после: добавления медиа владельцем, проверки и перевода в `status: approved`.

### Медиа — каждый четверг (на 11 дней вперёд)
- Залить на хостинг в `/0s3/blogger-data/media/catden/<дата>/` медиа постов ближайших 11 дней по `docs/catden-media-manifest-2026-11-19-2027-01-18.md` (и/или rolling-срезу).
- **Перед заливкой:** сверить, что уже залито на хостинге (список каталогов/файлов), чтобы не дублировать и не пропустить.
- **После публикации:** удалять отработавшие медиа (даты < сегодня).
- Выполнение FTP-заливки/сверки/удаления — по задаче владельца (агент при наличии доступа); исходные медиа к четвергу должны быть готовы.

### Вычитка — каждую пятницу (канал «календарь»)
- В приватный канал «календарь» (ключ `calendar` в `local/tokens.json`, `POST /messages` без `notify`, правило 2г AGENTS.md) отправлять подборку на ближайшие 10 дней: посты в порядке публикации, **с содержимым как будет публиковаться (текст + медиа), без дат**.
- Источник медиа для превью: **хостинг** (`/0s3/blogger-data/media/catden/<дата>/`), залитый в четверг. Для альбомов — все вложения; для постов без медиа — только текст; для draft без медиа — текст с пометкой, что медиа от владельца ещё не залито.
- Учёт ограничений: ≤4000 символов/сообщение, загрузка медиа через upload-API при отправке превью.
