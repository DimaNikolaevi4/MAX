# Стиль канала «example»

Учебный канал для отработки методики. Заполните этот файл по каждому реальному
каналу — ИИ-агент перед написанием поста читает его целиком.

## Тон
- Тёплый, обращение к читателю на «вы».

## Что публикуем
- Новости проекта, анонсы, полезные советы.

## Оформление
- 1–3 абзаца, при необходимости подзаголовки и списки.
- Эмодзи умеренно (0–3 на пост), без мигающих картинок.

## Запрещено
- Кликбейт, агрессивные призывы, обещания без доказательств.
- Упоминание токенов и личных данных.
