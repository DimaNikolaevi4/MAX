🤖 **Доступные из России ИИ-агенты: что реально работает**

Под каждым постом один и тот же вопрос: «А что из этого доступно из России без танцев с бубном?» Собрали честное сравнение. Без «просто используйте VPN» — это не ответ, а отговорка.

🇨🇳 **Китайские: бесплатно, без VPN**

**Qwen Agent (Alibaba).** Консольный Qwen Code плюс отдельные Qwen Work для Windows и Mac. Базовый тариф бесплатен, карта не нужна, работает из России. Платные тарифы — через Alipay.

**DeepSeek Agent.** Роскомнадзор не блокировал. Чат иногда нестабилен, API работает ровно. Yandex AI Studio даёт бизнесу агентов на DeepSeek-V3.2.

**[Z.ai](https://z.ai/) (GLM).** GLM-5.3 с контекстом 1M токенов. Десктопный агент Zcode — в open source с сентября 2026.

🇷🇺 **Российские: локально, но пока догоняют**

**GigaChat (Сбер).** GigaPlatform AI Studio — бесплатный конструктор агентов без программирования. Голос, документы, экспорт в PDF/HTML/Markdown. Вход по Сбер ID.

**Yandex AI Studio.** Анонсирован агент для бизнеса: до 30–50% офисных задач — отчёты, договоры, сводки встреч. DeepSeek-V3.2 уже доступен через Yandex Cloud.

**Другие.** Зрелые платформы для сборки: GigaChat Enterprise, Agent Platform (Just AI), MWS AI Agents Platform (МТС).

🇺🇸 **Западные: мощно, но с препятствиями**

**ChatGPT Agent.** Только с тарифа Plus. Из России официально закрыт — OpenAI блокирует IP с 2023 года. Нужен зарубежный IP и карта.

**Claude Agent.** Не рекомендуем. Anthropic массово блокирует аккаунты из России даже с VPN.

**Google Gemini.** Недоступен с российских IP, подписка — только с зарубежной картой.

**Perplexity.** Сам сервис открыт без VPN, базовая агентность бесплатна. Сложность только с оплатой Pro.

**OpenCode.** Бесплатный агент для кодинга. Работает из коробки, без регистрации и VPN.

**Replit Agent.** Открывается из России, но оплата через Stripe не проходит с карт РФ.

⚡ **Личный опыт: почему я выбрал [Z.ai](https://z.ai/)**

Из всего зоопарка мне больше зашёл браузерный агент [Z.ai](https://z.ai/) ([chat.z.ai](https://chat.z.ai/)). Выдаю ему токен к репозиторию на GitHub с документами — и он работает сам.

Кейс: загрузил книги по геотектонике, техкарты и акты. Задача — проанализировать, подтянуть ГОСТы из интернета и собрать отчёт. Справился: сверил данные, оформил и запушил готовый DOC прямо в репозиторий.

Заняло около получаса. Это не зависание — это нормальная работа над объёмной задачей. Всё это время я занимался другими делами, а потом забрал готовый файл.

Разница между чатом и агентом именно в этом. Чат — звонок. Агент — сотрудник, который пошёл, поработал и принёс результат.

🛠 **Что выбрать под задачу**

✅ Бесплатно и без VPN → Qwen, Perplexity (базовый)
✅ Для кодинга → OpenCode, [Z.ai](https://z.ai/) (Zcode)
✅ Для бизнеса на русском → GigaChat, Yandex AI Studio
✅ ChatGPT Agent → Plus + DNS/VPN
✅ Claude → не рекомендуем
✅ Всё сразу → агрегаторы ([syntx.ai](https://syntx.ai/), [gptunnel.ru](https://gptunnel.ru/))
