# Роль crossposter — бот «Кросс Автопостинг» (@se14808890_1_bot)

Сервисный бот для **пользовательских** каналов MAX (помощь сторонним авторам).
Собственные каналы проекта ведёт первый бот (`@se14808890_bot`) — этот бот к ним
не подключается.

- Дорожная карта: `docs/bot2-roadmap.md` (этапы 1–6+).
- Статус: **этап 1 «Старт + автоответ»** — код готов, ждёт токена и тестов.
  Срок этапа — до 21.11.2026.

## Файлы

| Путь | Назначение |
| --- | --- |
| `src/bot.py` | резидентный слушатель long polling (`GET /updates`, marker в `local/bot2-state.json`): приветствие на `bot_started`, меню-кнопки (`inline_keyboard` + `POST /answers`), автоответы по ключевым словам, fallback |
| `local/tokens.json` (ключ `bot2`) | токен бота — заполняется скриптом `local/bot2_register.py` (владелец кладёт токен в `local/bot2-token.txt`, скрипт проверяет `GET /me`, пишет ключ и удаляет файл) |
| `local/bot2-state.json` | маркер long polling (в git не попадает) |
| `local/logs/crossposter-bot.log` | журнал слушателя (UTF-8) |

## Запуск (после регистрации токена)

```
py roles\crossposter\src\bot.py
```

Останов: Ctrl+C. Повторный запуск с живым инстансом заблокирован lock-файлом
`local/bot2-listener.lock`.

## Ограничения и заметки

- Long polling — только для разработки/теста: платформа рекомендует webhook
  (`POST /subscriptions`), но он требует публичного HTTPS-URL; у нас локальная
  машина, поэтому polling.
- Лимиты: 2 сообщения/сек на чат, 30 rps на API (пауза между отправками 1.2 с).
- События: `bot_started`, `message_callback`, `message_created`,
  `bot_stopped`, `dialog_removed` (фильтр в запросе).
- Изменение описания/названия бота = повторная модерация — учесть при этапах 3–4.
