# Стиль канала «Нейро Мульт Студия» (tg_neuro) — канонический telegram-формат

Канал: https://t.me/Neuro_Animation_Studio

Творческая зона (где применимо в рамках telegram-формата): первый абзац и нижние блоки можно писать свободно, порядок подписки/реакции/вопроса не фиксировать — это защищает от замыливания глаз.

`format_profile: telegram`. Режим миграции: аудитория переливается в `ainow`
(https://max.ru/channel_ainow). Публикация — через релей
`deploy/tg-relay.php` инструментом `roles/blogger/tools/publish_telegram.py`.

## Медиа и заголовок

- Пост начинается с **фото** из архива `ainow`:
  `py roles/blogger/tools/pick_image.py --channel tg_neuro`.
  Пропорции ≥ 1,50; свои карточки не рисуются.
- Подпись ≤ **1000 знаков**.
- Заголовок — жирный, с эмодзи, ≤ 60 знаков, без точки в конце.
- Воздух между блоками; под подзаголовками пустой строки нет.
- Жирных выделений в абзацах ≤ 6, подзаголовки не считаются.

## Ссылки и порядок блоков

- **Минимум 1 прямая ссылка** на конкретный уже опубликованный пост `ainow`
  внутри текста.
- Порядок: заголовок → тело → [призыв к реакциям] → [вопрос необязателен] →
  пустая строка → CTA.
- Призыв к реакциям — ≤ 1 строки, минимум 2 поста между, по общему реестру
  `roles/blogger/config/reactions-registry.json`.
- Вопрос допустим внутри текста, отдельным блоком не обязателен.
- **CTA — последняя строка, без `> `:**
  `**Подписывайтесь на AI** — <фраза>`
  с жирной ссылкой на `https://max.ru/channel_ainow` и inline-кнопкой
  (`button_url` из front matter или `cta_url` канала).

## Пауза

Пост с полем `hold: <причина>` не публикуется. Снятие `hold` — только по прямой
команде владельца.

## Запрещено

Генерация собственных изображений, публикация без фото, ссылки кроме CTA и
ссылки на `ainow`, закреп без команды владельца, работа в личке бота AI Now.
