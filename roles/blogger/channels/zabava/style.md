# Стиль канала «Забавное» (zabava)

Канал: https://max.ru/channel_zabava
Позиционирование: лёгкий юмор и забавные моменты из жизни домашних питомцев
и диких животных. Короткие видео, которые поднимают настроение.
Статус: правила согласованы с владельцем (08.11.2026).

## Структура поста

Как в образце https://max.ru/channel_zabava/AaCVjEaVTiI:

1. видео (или изображение) — вложением, открывает пост;
2. короткий текст — 1–2 строки, до 200 символов;
3. пустая строка;
4. призыв — отдельной строкой в конце, с жирной ссылкой на канал.

## Формат поста (обязательные правила)

### 1. Видео первым

- Пост открывается видео: видео и есть обложка, отдельная картинка не нужна.
- По умолчанию — один ролик на пост. Допустимо до 12 вложений, но это исключение.
- Видео загружается через `POST /uploads?type=video`; после загрузки сервер
  обрабатывает файл — отправлять сообщение сразу нельзя, нужна пауза и повтор
  при ошибке `attachment.not.ready`.

### 2. Фото — исключение

- 97 из 100 последних постов — видео; фото допустимо, если нет подходящего
  ролика. Одиночное фото или альбом до 6 штук.
- Картинки не генерируются: владелец присылает файл.

### 3. Короткий текст

- **1–2 строки, до 200 символов.** Простыни и несколько абзацев — не формат.
- Одна мысль: реплика, вопрос или короткая шутка. **Точка в конце не ставится.**
- Пустая подпись не используется: текст обязателен.
- По статистике канала медиана подписи — 12 символов, 90-й процентиль — 87.
  Ориентируйтесь на этот диапазон, 200 — верхняя граница.

### 4. Тон

- Добрый юмор без злости и унижения; никакой политики, жестокости, шока.
- Вопрос к читателю уместен, но не обязателен.
- Эмодзи — **0–2** на пост, не в каждом посте (в канале эмодзи примерно
  в 10% постов).

### 5. Без хештегов и лишних ссылок

- Хештеги не используем.
- Единственная ссылка в посте — призыв на сам канал «Забавное».
- Кросс-промо на другие каналы (включая `ainow`) — только по прямому указанию
  владельца.

### 6. Призыв — в каждом посте

- Призыв обязателен, стоит последней строкой, **через пустую строку** после
  текста.
- Формат: `Подпишись на канал Забавное — <причина> 🎬`.
- **Без кавычек.** Слово `Забавное` — **жирная ссылка** на
  https://max.ru/channel_zabava, остальная фраза — обычный текст.
- Пул фраз — `roles/blogger/channels/zabava/cta-phrases.json`. Фраза выбирается
  случайно и **не повторяется в последних 6 постах**.
- Обещание «каждый день» и жёсткий график не используем.
- Старые опубликованные посты с прежним призывом не трогаем — новое правило
  действует для новых постов.

### 7. Разметка MAX

- По умолчанию — простой текст. Жирный и курсив допустимы, но не обязательны.
- MAX не рендерит markdown-списки и таблицы — маркеры останутся символами.
- Жёсткий лимит API — 4000 символов; практический для канала — текст до 200
  плюс призыв.

### 8. Люди в кадре

- Разрешены, в том числе дети, если у владельца есть права на видео.
- Ответственность за согласие людей на съёмку — на владельце.

## Частота публикаций

- **Свободный график**: выходим, когда есть что показать, без обещаний
  ежедневного поста.
- Технический предохранитель — не более 3 постов в сутки, чтобы не спамить.
- Время публикации — на усмотрение владельца.
- Не более 2 сообщений в секунду к API.

## Контент

- **Только животные и питомцы**: домашние и дикие, смешные моменты, милые
  истории, забавные реакции, курьёзы.
- Источник видео — владелец. Видео можно скачивать на компьютер, но **в git
  не добавлять**; рабочая папка — `local/video/zabava/` (gitignored).
- Использовать только свои или разрешённые ролики; без чужих водяных знаков
  и логотипов других каналов.

## Технические параметры видео

- Форматы: MP4, MOV, MKV, WEBM.
- Размер одного файла — до 250 МБ (лимит API MAX).
- После загрузки — дождаться обработки; при `attachment.not.ready` повторять
  с увеличивающимся интервалом.
- Один токен загрузки = один файл; токен можно переиспользовать для повторной
  отправки того же видео.

## Публикация

- Публикатор: `roles/blogger/tools/publish_video.py`.
- `publish_post.py` для этого канала не подходит: он поддерживает только
  картинку и требует CTA-цитату в формате `ainow`.
- `publish_video.py` сам подставляет призыв из пула, проверяет видео, делает
  GET-контроль и обновляет front matter.
- Перед публикацией: `git pull --rebase origin main`, дерево чистое, файл
  в `status: draft`, дата совпадает.
- После публикации: `GET /messages/{mid}` — вложение `video` на месте, текст
  и призыв совпадают; коммит и отчёт.

## Правка и удаление

- Правка текста — `PUT /messages?message_id=...` без вложений: видео
  сохраняется. Автопилот: применить, проверить GET, добавить `edited_at`,
  закоммитить, отчитаться.
- Удаление — только по прямой команде владельца (дубли, ошибки).

## Запрещено

- Публикация без видео или фото.
- Публикация без призыва и без ссылки на канал в призыве.
- Обещание ежедневного выхода или жёсткого графика в тексте и призыве.
- Скачивание видео в git-репозиторий.
- Генерация видео и картинок без прямого указания владельца.
- Реклама и ссылки без согласования; реклама без маркировки.
- Политика, жестокость, опасные трюки, шок-контент, медицинские и юридические
  советы.
- Контент не про животных и питомцев.
- Публикация чаще 3 постов в сутки.
