# Методика заставок канала na100 (введена 11.11.2026)

Заставка — верхнее изображение/видео поста-дайджеста. Документ описывает,
как делается, чем генерируется и какие ловушки обойти. Приоритет источников
изображений (Commons → фотобанки → заставка) описан в `style.md` канала;
эта методика — про последний вариант и про наложение на пользовательские фоны.

## Авто-тема по фону и проверка 16:9 (введено 11.11.2026)

Оба инструмента по умолчанию (`--theme auto`) сами определяют тему:

- фон сэмплируется по зонам раскладки (мачхед и панель «ФОРМАТ»);
- для каждой темы считается эффективный фон зоны (пиксели, смешанные
  с подложкой темы) и контраст WCAG-подобного отношения с цветом текста;
- побеждает тема с большим контрастом в худшей зоне — текст всегда
  противоположен фону (тёмный фон → светлый текст, светлый → тёмно-синий).
  Модуль: `roles/blogger/tools/cover_theme.py`. Ручной `--theme dark|light`
  сохранён как override.

Перед раскладкой фон проверяется на **16:9** (обложки канала — 2752×1536
и 1920×1080, оба ~16:9): в пределах допуска ±15% — центр-кроп до точных
16:9; вне допуска (4:3, 3:2, портретные) кадр бракуется — пайплайн берёт
следующий источник или заставку. У видео-инструмента кроп делается
ffmpeg-фильтром `crop` до наложения текста.

## Палитра

- тёмный фон (`--theme dark` у photo-инструмента): текст белый, акцент
  `#3edb9a`, подзаголовок `#7fffd4`, служебные строки `#8fb8c8`; слева
  градиент затемнения, панель — чёрная с прозрачностью ~47%.
- светлый фон (`--theme light`): текст тёмно-синий `#16305E`, акцент
  `#1f9d66`, служебные `#4a6e8c`; панель — белая с прозрачностью ~72%.

Шрифт: Segoe UI Bold (`segoeuib.ttf`) / Semibold (`seguisb.ttf`), есть на
любой Windows 10/11 — доп. файлов не требует.

## Типовые команды

```powershell
# заставка «с нуля» (без фото)
py roles\blogger\tools\digest_cover.py --style paper --title "Новости" `
  --title2 "мира техники" --subtitle "выпуск №2 · итоги суток" `
  --items "Microsoft против запрета|Видеокарты подорожают?|Pixel Tag против AirTag|ИИ и ядерная повестка|Гибридные сети за 4,5 часа" `
  --out local\digest\cover-second-issue.png

# раскладка paper на тёмной картинке
py roles\blogger\tools\digest_cover_photo.py --theme dark --bg <фон.png> `
  --items "Скандал в Nvidia|IPO Anthropic: до $1,4 трлн|Google: ИИ-чипы и рой агентов|Alibaba T-Head на IPO|Санкции против банков" `
  --out local\digest\cover-YYYY-MM-DD.png

# раскладка paper на светлом видео
py roles\blogger\tools\digest_cover_video.py --theme light --src <фон.mp4> `
  --items "..." --out local\digest\cover-YYYY-MM-DD.mp4
```

`items` берутся из заголовков выпуска (файл поста, блоки «Мир/Китай/Россия»),
формулировки сокращаются до 3–5 слов.

## Пайплайн публикации проб/вариантов

1. Заставка сохраняется в `local/digest/` (в git не идёт, `local/*` в
   `.gitignore`).
2. Копия поста с текстом выпуска (`status: draft`, `image_file:` или
   `video_file:`) кладётся в `roles/blogger/channels/na100/posts/`
   с именем вида `2026-11-11-test-zastavka-N-<имя>.md` — draft не
   подхватывает планировщик.
3. Публикация: `py roles\blogger\tools\publish_post.py --channel na100 <файл>`
   (env: `MAX_HTTP=python`, `MAX_CA_CERT=local/russian_ca_bundle.pem`).
4. Ссылки на все варианты собираются в ответе пользователю; закреплять
   ничего нельзя — закреп в канале ставится только по явной команде
   пользователя (решение 11.11).
5. Выбранный вариант фиксируется в этом документе и `style.md`.

## Ловушки (проверены на практике 11.11)

- **ffmpeg недоступен в PATH** — брать из пакета `imageio-ffmpeg`
  (`imageio_ffmpeg.get_ffmpeg_exe()`), ставится через pip.
- **drawtext и пути**: в filtergraph пути с `:` (диск Windows) и кириллицей
  ломают парсер. Решение: копировать шрифт и textfile-файлы во временную
  папку, использовать короткие имена, ffmpeg запускать с `cwd=` этой папки.
- **`\r\n` в textfile**: `Path.write_text()` на Windows пишет `\r\n`,
  а drawtext трактует `\r` как второй перенос — многострочный текст
  «разъезжается» (строка наезжала на подзаголовок). Решение:
  `write_text(..., newline="\n")` или каждую строку отдельным drawtext.
- **Кадр из видео**: для одного PNG-кадра ffmpeg требует `-update 1`
  (или pattern `%03d`).
- **PowerShell съедает `$`**: в двойных кавычках `$1` — переменная PS
  (`--items "...$1,4 трлн..."` превратится в `",4 трлн"`). Строки с долларом
  передавать в одинарных кавычках или из файла-скрипта.
- **Кириллица в консоли**: PowerShell ломает inline-python с кириллицей —
  сложные скрипты писать в файл и запускать `py file.py`.
- **Планировщик**: `schtasks` из PowerShell чувствителен к кавычкам в
  `/tr` — команду обернуть в `cmd /c '...'`.
- **Мусорные символы при записи md/json**: после записи проверять файл
  на `[\u4e00-\u9fff]` и нестандартные слова.
