# Стиль канала na100 — ежедневный техно-дайджест

Канал: https://max.ru/channel_na100

Творческая зона (AGENTS.md §0.11): первый абзац и хвост пишутся свободно; при `tail_mode: free` во front matter набор и порядок элементов хвоста (подписка/реакция/вопрос) произвольные.

## База

Общие правила формата — `AGENTS.md` §0 FORMAT CORE v1. Ниже — только дельты
канала. `format_profile: core`, новым постам ставится `format_core: 1`.

- **Хук = жирный заголовок ≤ 60 знаков**, без точки. Не отдельная строка-хук
  40–60 знаков, а обычный жирный заголовок поста.
- Вопрос к читателю есть **в каждом выпуске** — обязательный последний блок
  по §0 (прежняя дозировка 2–3 выпуска в неделю отменена). Без «проверить/
  проверили»: лучше «какую новость разобрать подробнее?», «о чём рассказать?».
- Подзаголовки пунктов идут без пустой строки после них; между смысловыми
  блоками — пустая строка.
- Ориентир длины — **3400–3700 знаков**; жёсткий потолок §0 — 4000.
- Ссылки в тексте запрещены, кроме CTA (правило «никаких внешних ссылок,
  кроме CTA» сохраняется).
- CTA: чередование `self` ↔ `ainow` через `cta_target: self | ainow`
  во front matter; без поля — `self` + предупреждение владельцу.

## Формат выпуска

1. Пять новостей: 1 Россия + 1 Китай + 3 мира; при пустом Китае — 1 РФ + 4 мира
   с пометкой. Порядок подачи перемешивается при сборке.
2. У каждой новости: жирный подзаголовок с номером `1️⃣ …`; «Что случилось» —
   1–2 предложения фактов; «Почему важно» — 1–2 предложения следствия.
3. Короткий итог — 1–2 строки причинной связкой, не перечислением.
4. Одна шутка на выпуск — у той новости, где она естественна; стоп-лист
   тем для юмора жёсткий (жертвы, болезни, религия, национальность, внешность).
5. Цифра в подзаголовке — минимум 2 из 5; «почему важно» — следствие, а не
   пересказ; жирных якорей внутри абзаца — 1–2 на пункт.

## Обложка и атрибуция

- Заставка — по `roles/blogger/channels/na100/cover-method.md`:
  `digest_cover_photo.py`, тема по фону, авто-вуаль, панель «ФОРМАТ».
- Полная атрибуция — только в `digests/<дата>-draft.json`; в текст не попадает.
  В посте допустимы короткие «по данным SCMP» и подпись «Фото: …» без URL.
  Обязательна атрибуция **только для чужого фото**; сгенерированная заставка
  из `local/digest/cover-*` или фона `images/fallback/` её не требует
  (`check_digest_extras` проверяет `image_file`).
