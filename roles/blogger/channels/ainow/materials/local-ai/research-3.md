# Исследование инструментов локального ИИ — пакет 3

Проверено 24.11.2026. Источники: официальные сайты, репозитории GitHub и GitHub Releases API. Даты активности — по `pushed_at` и последнему релизу репозитория. Неподтверждённые детали помечены как «НЕ ПОДТВЕРЖДЕНО».

## Категория «Медиа, генерация и обработка»

### ComfyUI
- Статус проверки: ПОДТВЕРЖДЕНО. Репозиторий `Comfy-Org/ComfyUI`, последний релиз v0.46.0 от 18.11.2026, коммиты идут 24.11.2026; ~148 тыс. звёзд. Проект переехал с `comfyanonymous/ComfyUI`.
- Что это и какую задачу решает: узловой (graph/nodes) интерфейс и бэкенд для генерации изображений и видео локальными diffusion-моделями; позволяет собирать собственные пайплайны из нод.
- Платформы: Windows, Linux, macOS (в т.ч. portable-сборки для NVIDIA/AMD/Intel, ARM64); веб-интерфейс в браузере.
- Работа с моделями: из коробки — подключение локальных чекпоинтов SD/FLUX/видеомоделей и множество кастом-нод; есть REST/WebSocket API и Comfy Router с облачными партнёрскими нодами; Ollama подключается через сторонние текстовые ноды (не нативно).
- Лицензия и цена: GPL-3.0, бесплатно. Есть коммерческий хостинг comfy.org (не обязателен).
- Ограничение или подводный камень: порог входа выше, чем у однокнопочных GUI — нужно разбираться в нодах и в управлении VRAM; в v0.46 удалена поддержка DirectML.
- Источники: https://github.com/Comfy-Org/ComfyUI ; https://www.comfy.org/

### InvokeAI
- Статус проверки: ПОДТВЕРЖДЕНО. `invoke-ai/InvokeAI`, релиз v6.14.4 от 03.11.2026, коммиты 24.11.2026; ~29 тыс. звёзд.
- Что это и какую задачу решает: полноценная creative-среда с WebUI для генерации изображений и видео локальными моделями; ориентирована и на художников, и на продакшн (лежит в основе нескольких коммерческих продуктов).
- Платформы: Windows, Linux, macOS; запуск через установщик/Docker, веб-интерфейс.
- Работа с моделями: из коробки — менеджер моделей и starter-модели; можно добавлять свои чекпоинты/LoRA; есть REST API и OpenAI-совместимые эндпоинты; Ollama нативно не заявлена (НЕ ПОДТВЕРЖДЕНО).
- Лицензия и цена: Apache-2.0, бесплатно; коммерческие продукты на той же базе — отдельно.
- Ограничение или подводный камень: тяжёлая установка и зависимости (в последнем релизе как раз чинили падение стартапа из-за бага Starlette); нужен дискретный GPU с заметным VRAM.
- Источники: https://github.com/invoke-ai/InvokeAI ; https://invoke-ai.github.io/InvokeAI/

### Fooocus
- Статус проверки: ЧАСТИЧНО (проект жив, но разработка затихла). `lllyasviel/Fooocus`, последний релиз v2.5.5 от 12.08.2024, последний коммит 01.12.2025, архивом не помечен; ~54 тыс. звёзд.
- Что это и какую задачу решает: «однокнопочная» генерация изображений в стиле Midjourney на локальной машине: минимум настроек, автоматический подбор параметров prompt.
- Платформы: Windows, Linux, macOS; запуск через .bat/.sh или Docker.
- Работа с моделями: из коробки — базовые модели скачиваются автоматически при первом запуске; свои модели кладутся в папку `models`; Ollama не используется, отдельного публичного API НЕ ПОДТВЕРЖДЕНО.
- Лицензия и цена: GPL-3.0, бесплатно.
- Ограничение или подводный камень: более двух лет без новых релизов — новые модели (например, свежие video/flux-пайплайны) могут не поддерживаться; для 2026 года это скорее «рабочий музейный инструмент», чем активный продукт.
- Источники: https://github.com/lllyasviel/Fooocus ; https://github.com/lllyasviel/Fooocus/releases

### Draw Things
- Статус проверки: ПОДТВЕРЖДЕНО. `drawthingsai/draw-things-community`, релиз v26.1023.0 от 23.10.2026, коммиты 23.11.2026; основной код в приватном монорепозитории, публичный — community-зеркало с синхронизацией на каждый коммит.
- Что это и какую задачу решает: нативный движок генерации и приложение для генерации изображений на Apple Silicon с упором на скорость и приватность (вся генерация на устройстве); есть LoRA-тренировка и серверный режим.
- Платформы: macOS и iOS (приложение в App Store); плюс gRPCServerCLI для macOS и CUDA-Linux (RTX 20xx–40xx, A100–H100) и CLI `draw-things-cli` через Homebrew.
- Работа с моделями: из коробки — модели скачиваются внутри приложения; свои чекпоинты/GGUF/LoRA добавляются локально; есть self-hosted gRPC-сервер (Server-Offload) и CLI, Ollama не нужна.
- Лицензия и цена: GPL-3.0 у community-репозитория; само приложение распространяется через App Store — точная модель монетизации НЕ ПОДТВЕРЖДЕНО (в README не указана).
- Ограничение или подводный камень: основной продукт — закрытый монорепозиторий, публичный репозиторий содержит только часть кода и требует CLA для контрибуций.
- Источники: https://github.com/drawthingsai/draw-things-community ; https://drawthings.ai

### Diffusion Bee
- Статус проверки: ЧАСТИЧНО (сайт жив, код застыл). `divamgupta/diffusionbee-stable-diffusion-ui`, последний релиз 2.5.3 от 14.08.2024, последний коммит 30.10.2024; ~13,6 тыс. звёзд. Сайт diffusionbee.com отвечает и предлагает скачивание под macOS.
- Что это и какую задачу решает: простейший способ запустить Stable Diffusion локально на Mac без зависимостей: текст-в-картинку, image-to-image, upscale, generative fill, обучение моделей.
- Платформы: только macOS (сайт указывает macOS 13.1+, рекомендуется Apple Silicon).
- Работа с моделями: из коробки — встроенные модели; можно добавлять свои (открытый формат); API и Ollama не заявлены (НЕ ПОДТВЕРЖДЕНО).
- Лицензия и цена: AGPL-3.0 в репозитории; сгенерированные изображения — по лицензии CreativeML Open RAIL-M (указано на сайте). Цену скачивания сайт не раскрывает (НЕ ПОДТВЕРЖДЕНО).
- Ограничение или подводный камень: репозиторий не обновлялся почти 2 года — функциональность застыла на уровне 2024 года; для серии постов «живые инструменты 2026» лучше не включать без оговорки.
- Источники: https://github.com/divamgupta/diffusionbee-stable-diffusion-ui ; https://diffusionbee.com

### Whisper Desktop
- Статус проверки: ЧАСТИЧНО. Репозиторий `Const-me/Whisper` ( gui-обвязка над Whisper на C++/GPGPU), последний релиз 1.12 от 22.07.2023, но коммиты продолжались до 22.09.2026, архивом не помечен; ~10,7 тыс. звёзд.
- Что это и какую задачу решает: десктопное приложение для локального распознавания речи (speech-to-text) через модель OpenAI Whisper с аппаратным ускорением — транскрибация аудио без облака.
- Платформы: Windows (GUI-приложение; бэкенд GPGPU через Direct3D 11 / CPU).
- Работа с моделями: модели Whisper в формате GGML нужно скачивать отдельно (из коробки не идут); свои модели — только совместимые конвертированные Whisper; Ollama не используется; публичный API в репозитории НЕ ПОДТВЕРЖДЕНО.
- Лицензия и цена: MPL-2.0, бесплатно.
- Ограничение или подводный камень: свежего релиза нет с 2023 года — интерфейс и поддержка новых форматов могут отставать, хотя код изредка правится; не путать с `ggerganov/whisper.cpp` (там активный релиз v1.9.6 от 23.11.2026).
- Источники: https://github.com/Const-me/Whisper ; https://github.com/ggerganov/whisper.cpp

### Upscayl

### GPT-SoVITS
- Статус проверки: ПОДТВЕРЖДЕНО. Канонический репозиторий `RVC-Boss/GPT-SoVITS` (зеркало `bilibili/GPT-SoVITS`: MIT, коммиты 11.11.2026, последний релиз `20250606v2pro` от 06.06.2025, ~64 тыс. звёзд).
- Что это и какую задачу решает: few-shot генерация и клонирование речи: 5 секунд образца дают zero-shot TTS, 1 минута данных — дообучение голоса; есть кросс-лингвальная генерация и инструменты подготовки датасета.
- Платформы: Windows, Linux, macOS (Python 3.10–3.12, PyTorch/CUDA 11.8–12.8, Apple Silicon); есть Docker и Colab.
- Работа с моделями: из коробки — базовые веса; свои модели — обучение на своём голосе (1 мин+); есть сторонние API-форки (например, GPT-SoVITS-fast-api), Ollama не используется.
- Лицензия и цена: MIT, бесплатно. Веса/датасеты могут иметь свои условия — проверять отдельно.
- ⚠️ **Этический/правовой риск (обязательно отметить в посте):** нужен осознанный consent владельца голоса; клонировать чужие голоса без разрешения нельзя — это риск подмены, мошенничества и нарушения прав на персональные данные/голос. Не демонстрировать клонирование голосов известных людей без явного разрешения.
- Ограничение или подводный камень: качество сильно зависит от качества и чистоты исходной записи; китайские/японские/корейские модели лучшего качества, русский язык может работать хуже (НЕ ПОДТВЕРЖДЕНО авторитетным источником — проверить перед публикацией).
- Источники: https://github.com/RVC-Boss/GPT-SoVITS ; https://github.com/bilibili/GPT-SoVITS

### YuE
- Статус проверки: ПОДТВЕРЖДЕНО (название уточнено: сейчас это **YuE2**). `multimodal-art-projection/YuE`, последний релиз `yue2-v0.1.6` от 09.09.2026, коммиты до 01.11.2026; ~13,7 тыс. звёзд; Apache-2.0. Исходный YuE v1 сохранён в ветке `YuE-v1`.
- Что это и какую задачу решает: генерация полноценных песен по тексту и стилю: сначала символический план (мелодия, аккорды), затем рендер с вокалом и аккомпанементом; позиционируется как открытая альтернатива Suno с редактируемой композицией.
- Платформы: Linux/Windows через Python (CUDA), модели на Hugging Face; есть веб-демо и ComfyUI-ноды от сторонних авторов; macOS-приложение YuE Studio — сторонний проект.
- Работа с моделями: из коробки — веса `YuE2-3B` на Hugging Face; свои веса/LoRA можно подключать; Ollama не нужна; ставка на открытые веса и символический control.
- Лицензия и цена: Apache-2.0 у кода; условия конкретных весов и датасетов на Hugging Face нужно проверять отдельно. Есть бесплатное онлайн-демо.
- Ограничение или подводный камень: очень требователен к VRAM и времени генерации; репозиторий быстро эволюционировал (v1 → YuE2), поэтому старые гайды и ComfyUI-ноды могут быть несовместимы. В посте использовать название «YuE (сейчас YuE2)».
- Источники: https://github.com/multimodal-art-projection/YuE ; https://map-yue2.github.io/

### Nvidia Broadcast
- Статус проверки: ПОДТВЕРЖДЕНО. Официальная страница NVIDIA жива, текущая версия приложения 2.3.0 (ссылка на release notes и инсталлятор 2.3.0 на сайте); SDK-редистрибутивы датированы 2025–2026 гг.
- Что это и какую задачу решает: локальные AI-эффекты для камеры и микрофона — шумоподавление, удаление эха, виртуальный фон, авто-кадрирование, коррекция взгляда в камеру, а также офлайн-обработка файлов и MCP-сервер для управления агентом.
- Платформы: только Windows 10/11 64-bit и Windows 11 on Arm; требуется GPU NVIDIA GeForce RTX 2060 / Quadro RTX 3000 / TITAN RTX / RTX Spark или старше, 8 ГБ RAM. Linux/macOS — только сторонние неофициальные проекты.
- Работа с моделями: проприетарные модели в комплекте, свои модели подключить нельзя; Ollama/API для моделей нет (есть только MCP-управление приложением); для разработчиков — Broadcast SDK (Maxine).
- Лицензия и цена: проприетарное ПО NVIDIA, скачивание бесплатно (на странице нет цены); требуется совместимый RTX-железный набор.
- Ограничение или подводный камень: жёсткая привязка к RTX-железу и Windows — на AMD/Intel/Apple/linux не работает; это не «генератор контента», а улучшение видеозвонков/стримов, не путать с генерацией изображений.
- Источники: https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-app/ ; https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-sdk/resources/

### LumaBrowser
- Статус проверки: ПОДТВЕРЖДЕНО (название и проект уточнены). Это **LumaBrowser от LumaByte** (`amurgola/LumaBrowser`, сайт lumabyte.com), а НЕ сервис Luma AI (lumalabs.ai). Релиз v2.2.6 от 22.11.2026, коммиты 22.11.2026; ~154 звезды — молодой нишевый проект.
- Что это и какую задачу решает: десктопный Chromium-браузер со встроенным локальным ИИ: чат и агенты, генерация изображений/видео, TTS и музыка, работа с документами, MCP-сервер, чтобы Claude Code/Codex/Cline управляли браузером.
- Платформы: Windows, macOS, Linux; без аккаунта, без регистрации и без телеметрии (по заявлению сайта).
- Работа с моделями: из коробки — GPU-рантайм на базе llama.cpp и автоподбор модели под железо; есть OpenAI-совместимый API, REST/MCP/WebDriver/CDP; свои GGUF-модели подключаются; Ollama-совместимый эндпоинт может быть использован через OpenAI-API (совместимость явно НЕ ПОДТВЕРЖДЕНО).
- Лицензия и цена: сайт заявляет GNU AGPL и «free & open source»; GitHub API отдаёт `NOASSERTION` в метаданных лицензии — для поста безопаснее писать «AGPL по заявлению сайта», бесплатно.
- Ограничение или подводный камень: проект молодой (около 150 звёзд) и активно меняется; часть возможностей (например, «Hub» с календарями и почтой) требует входа в сторонние сервисы внутри браузера — это локальность ИИ, но не полная изоляция данных. Не путать с Luma AI.
- Источники: https://lumabyte.com ; https://github.com/amurgola/LumaBrowser

## Категория «Инфраструктура локального запуска»

### Ollama
- Статус проверки: ПОДТВЕРЖДЕНО. `ollama/ollama`, релиз v0.40.17 от 10.11.2026, коммиты 24.11.2026; ~188 тыс. звёзд.
- Что это и какую задачу решает: самый простой способ поднять локальные LLM одной командой — `ollama pull` + `ollama run`, с автоматическим выбором железа и управлением моделями.
- Платформы: Windows, macOS, Linux; есть Docker-образ и серверный режим.
- Работа с моделями: из коробки — библиотека готовых моделей (Kimi, GLM, MiniMax, DeepSeek, gpt-oss, Qwen, Gemma и др.); свои модели через Modelfile и GGUF; OpenAI-совместимый API и native CLI/SDK; Ollama — это и есть инструмент.
- Лицензия и цена: MIT, бесплатно. Отдельные модели в каталоге имеют свои лицензии.
- Ограничение или подводный камень: удобство достигнуто упрощением — тонкая настройка квантования и параметров ниже, чем у llama.cpp напрямую; модели в каталоге могут быть большими (десятки ГБ).
- Уже освещено: 2026-11-20, упоминание (пост ainow про OpenCode Zen).
- Источники: https://github.com/ollama/ollama ; https://ollama.com

### llama.cpp
- Статус проверки: ПОДТВЕРЖДЕНО. `ggml-org/llama.cpp` (переезд с `ggerganov/llama.cpp`), релиз v1.0.0 от 13.11.2026, коммиты 24.11.2026; ~136 тыс. звёзд. Важная веха — версия 1.0.
- Что это и какую задачу решает: движок инференса LLM на C/C++ с минимальными зависимостями — база для множества локальных оболочек; формат GGUF и квантование позволяют запускать модели на скромном железе.
- Платформы: Windows, Linux, macOS; CPU, CUDA, Metal, Vulkan, SYCL и др.; есть Docker.
- Работа с моделями: из коробки — конвертация HF-моделей в GGUF и готовые квантованные веса на Hugging Face; свой формат GGUF; встроенный `llama-server` с OpenAI-совместимым API; Ollama работает поверх llama.cpp-подобного стека, но это separate проект.
- Лицензия и цена: MIT, бесплатно.
- Ограничение или подводный камень: низкоуровневый инструмент — без оболочки придётся разбираться с флагами, квантованием и сборкой; документация разбросана между репозиторием и llama.app.
- Источники: https://github.com/ggml-org/llama.cpp ; https://llama.app

### LocalAI
- Статус проверки: ПОДТВЕРЖДЕНО. `mudler/LocalAI`, релиз v5.0.1 от 20.11.2026, коммиты 24.11.2026; ~50 тыс. звёзд.
- Что это и какую задачу решает: открытый AI-сервер, который поднимает локальные модели любых типов — LLM, зрение, речь, изображения, видео — и отдаёт их через OpenAI-совместимый API; работает и без GPU.
- Платформы: Windows, Linux, macOS; Docker/Kubernetes, CPU и GPU-бэкенды (CUDA, Metal, Vulkan и др.).
- Работа с моделями: из коробки — model gallery и'automatic setup'; свои модели через YAML-конфиги и локальные веса; OpenAI-совместимый API; может работать как бэкенд для other интерфейсов, в т.ч. с моделями из экосистемы Ollama (точная формулировка совместимости НЕ ПОДТВЕРЖДЕНО).
- Лицензия и цена: MIT, бесплатно.
- Ограничение или подводный камень: широкий охват моделей означает больше движущихся частей — конфиги и бэкенды сложнее, чем у Ollama; версия 5.x — крупный мажор, старые гайды могут устареть.
- Источники: https://github.com/mudler/LocalAI ; https://localai.io

### Pinokio
- Статус проверки: ПОДТВЕРЖДЕНО. `pinokiocomputer/pinokio`, релиз v8.4.1 от 24.11.2026, коммиты 24.11.2026; ~8,4 тыс. звёзд. Сайт pinokio.co.
- Что это и какую задачу решает: «AI Browser» / one-click launcher: установка и запуск любых open-source ИИ-проектов (ComfyUI, Ollama, генераторы и т.п.) без ручной возни с терминалом и зависимостями.

- Ограничение или подводный камень: скрипты могут выполнять произвольные команды — хоть Pinokio изолирует их в `~/pinokio` и проверяет каталожные скрипты вручную, сторонние скрипты нужно читать перед запуском.

### LMDeploy
- Статус проверки: ПОДТВЕРЖДЕНО. `InternLM/lmdeploy`, релиз v0.18.0 от 28.09.2026, коммиты 24.11.2026; ~8,1 тыс. звёзд.
- Что это и какую задачу решает: тулкит от InternLM для сжатия, деплоя и servings LLM — квантование (AWQ и др.) и быстрый инференс через TurboMind; ориентирован на продакшн и серверы, а не на «домашний чат».
- Платформы: Linux (основной фокус), Docker; NVIDIA GPU; есть поддержка OpenAI-совместимого API-сервера.
- Работа с моделями: из коробки — модели с Hugging Face, квантование и конвертация в TurboMind; свои HF-веса; OpenAI-совместимый API; Ollama не используется.
- Лицензия и цена: Apache-2.0, бесплатно.
- Ограничение или подводный камень: заметно более «инженерный» инструмент, чем Ollama/llama.cpp — без опыта с CUDA/серверным деплоем разворачивать сложно; на Windows локальный запуск не основной сценарий (НЕ ПОДТВЕРЖДЕНО для Windows).
- Источники: https://github.com/InternLM/lmdeploy ; https://lmdeploy.readthedocs.io/en/latest
