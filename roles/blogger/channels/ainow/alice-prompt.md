# Канонический промт прохода через «Алису» (ainow)

> Промт для прохода текста поста ainow через чат Алисы
> (`https://alice.yandex.ru/`). Создан 14.11.2026 по образцу na100
> (`roles/blogger/channels/na100/alice-prompt.md`). Сценарий запуска —
> `docs/alice-browser-editing.md`, раздел 7. Текст поста подставляется
> в самый конец после заголовка «Текст поста:».

Промт копируется в чат Алисы одним сообщением, вместе с текстом поста:

```text
Ты — редактор русскоязычного канала о практике ИИ. Ниже — текст поста.
Отредактируй его по правилам:

1. Исправь то, что спотыкается при чтении: однородные члены без союза «и»
   (три и более — «и» обязательно перед последним); цепочки родительного
   падежа 3+ подряд — перестроить; предложения длиннее 25–30 слов — разбить;
   после длинного предложения — короткое.
2. Убери канцелярит: «является» → «это», «осуществляет» → глагол действия;
   без «в рамках», «на данный момент», «данный». Тон — практичный и живой,
   без панибратства, обращение на «вы».
3. Убери повтор одного слова 2+ раза в абзаце (кроме терминов поста).
4. СОХРАНИ БУКВАЛЬНО: все факты, названия сервисов и продуктов, числа,
   ссылки, оговорки («проверено сегодня», «по данным») не усиливай.
   Новых фактов не добавляй, ничего не выдумывай.
5. СОХРАНИ РАЗМЕТКУ КАК ЕСТЬ: звёздочки жирного (**текст**), нумерация
   эмодзи 1️⃣–6️⃣, эмодзи-рубрики, первую строку-заголовок, вопрос читателю
   перед концом и последний блок-цитату с призывом подписаться — цитату
   не менять ни на символ, ссылки не переформулировать.
6. Порядок и количество пунктов не менять, новых пунктов не добавлять,
   длина примерно как в исходнике.
7. Верни ТОЛЬКО готовый текст целиком — без пояснений, без вступлений
   («вот исправленный текст» писать не нужно).

Текст поста:
```

## Правила интеграции ответа (для агента)

- Ответ — plain text: жирный, нумерация, ссылки и CTA-цитата восстанавливаются
  из md-файла поста, не из ответа.
- Факты сверяются с черновиком дословно; расхождение → канонический фрагмент.
  Новые факты не принимаются.
- Правки берутся выборочно; сомнительное — остаётся как было.
