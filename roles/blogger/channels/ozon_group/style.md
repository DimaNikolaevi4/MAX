# Стиль канала «Ozon Находки» (ozon_group) — режим миграции

## Контекст

- Канал закрывается: https://max.ru/channel_ozon_group (chat_id в
  `local/tokens.json`). Бот добавлен админом 10.11.2026.
- Тематика канала: находки и скидки Ozon (подборки товаров, промокоды,
  удачные покупки) — лёгкий коммерческий контент для экономной аудитории.
- Задача постов: перевести подписчиков в основной канал
  **AI** — https://max.ru/channel_ainow — до закрытия.
- Тон: дружелюбный, конкретный, «находки» — без давления; посты миграции
  должны быть полезными, а не «голой рекламой».

## Обязательный формат (наследуется от основного канала)

1. Пост начинается с изображения (вложение). **Изображение берётся из архива
   канала AI** — `py roles/blogger/tools/pick_image.py --channel ozon_group`,
   см. `AGENTS.md` раздел 5б. Свои карточки не рисуем.
2. Заголовок жирным, с тематическим эмодзи.
3. Воздух (`\n\n`) между блоками.
4. Маркеры списков литеральные `—` / `•` / 1️⃣ (MAX не рендерит
   markdown-списки — см. `roles/blogger/channels/ainow/style.md`, раздел 6).
5. Нижний блок: цитата-призыв
   `> **Подписывайтесь на [AI](https://max.ru/channel_ainow)** — <своя фраза>`.
6. Объём ≤ 4000 символов. Лимит API: 2 сообщения/с (пауза ≥ 0,6 с).

## Правила миграции

- Каждый пост напоминает, что канал закрывается, и ведёт в AI.
- В каждом посте — минимум 1 прямая ссылка на пост основного канала
  (формат https://max.ru/channel_ainow/...).
- Не обещать здесь новый контент — новый контент выходит в AI.
- Фразы призыва не повторяются между постами (реестр — `cta-phrases.json`).
