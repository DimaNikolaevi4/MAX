# Стиль канала «Коты, кошки и котята» (catden)

Канал: https://max.ru/channel_catden

## База

Общие правила формата — `AGENTS.md` §0 FORMAT CORE v1. Ниже — только дельты
канала. `format_profile: core`, новым постам ставится `format_core: 1`.

- CTA: строго `self` (`https://max.ru/channel_catden`), чередования нет.
- Перелинковка: **ровно 1** ссылка на уже вышедший пост канала по теме, внутри
  абзаца, не в CTA. Правило «ссылки только CTA» отменено.
- Текстовые посты без медиа разрешены (например, 002, 010-p2, 017, 018, 065, 076).
- Одиночное изображение text-поста — ≥ 1,50 по §0; альбомы под это правило
  не попадают.

## Ритм и альбомы

- Ритм: **день 1 — альбом-карусель серии, день 2 — текстовый пост этой же серии**.
  Внутри серии: `p1`, `p2`, …, затем `img1`, `img2`, …; альбом — накануне
  следующей текстовой части.
- Альбом-тизер для новых постов оформляется по каркасу `AGENTS.md` §0:
  **жирный заголовок ≤ 60 знаков**, затем CTA-цитата → пустая строка → вопрос
  (порядок по §0.6). Вариант фразы
  «На фото — герои завтрашней статьи» / «будущей статьи» — без тизеров и имён.
- Максимум 9 фотографий в карусели (предел в `channels.json`).

## Медиа

Медиа постов — **FTP/local**, в git не добавляются:
`/0s3/blogger-data/media/catden/<дата>/<файл>`. Исходники `nev/` также хранятся
только локально. Проверка готовности — `py roles/blogger/tools/media_aspect.py <файл>`
для одиночных изображений; ритм пар — `py roles/blogger/tools/plan_rhythm.py --channel catden`.

## Тон

Тёплый, простой, без канцелярита. Без политики, шока и жестокости.
Медицинские советы — только «обратитесь к ветеринару». Финальный вопрос —
по теме поста, не дежурный.

## Порядок серий в плане

Перемешивать: соседние дни должны отличаться темой и настроением — породный
справочник → человеческая история → другой справочник. Порядок внутри серии
не трогать.
