# Стиль канала «Коты, кошки и котята» (catden)

Канал: https://max.ru/channel_catden (slug `catden`, chat_id в
`local/tokens.json`). Позиционирование: породы кошек, истории о котах и
котятах, уход и здоровье. Создан 12.11.2026 на освободившемся после Ozon
слоте; материал — переработанные статьи из Яндекс.Дзена (папка `nev/`,
78 статей → 144 поста, из них 62 поста-альбома с иллюстрациями).

## График публикаций

- Ритм «пост — анонс — пост» (решение владельца 12.11.2026, вечер):
  **день 1 — пост (статья), день 2 — анонс поста дня 3 (2–3 слова) с
  каруселью «лишних» изображений серии, день 3 — следующий пост**.
  Если у серии нет иллюстраций — посты идут обычным «через день» (шаг 2).
- Старт 12.11.2026; 139 постов (144 минус 5 поглощённых альбомов),
  последний по плану 19.06.2027; 57 анонсов-каруселей (максимум 9 фото).
- Дата каждого поста зашита в имя файла: `YYYY-MM-DD-<slug>.md`, статус
  `approved`. Публикация — задачей Планировщика Windows
  «MAX catden - publish approved» (ежедневно 07:32 МСК; публикатор сам берёт
  посты, дата которых наступила: `roles/blogger/tools/publish_scheduled.py
  --channel catden`, обёртка `roles/blogger/bin/publish_scheduled_catden.ps1`).
- Внутри серии порядок: текстовые части статьи (p1, p2, ...), затем
  посты-альбомы с иллюстрациями (img1, img2, ...). Все img-альбомы серии
  склеены в один анонс (носитель img1, `image_files` — конкатенация),
  поглощённые img-файлы удалены.

## Структура поста

1. Картинка (или альбом до 6 штук) — вложение, открывает пост.
2. Текст статьи — markdown, жирные подзаголовки, лимит 4000 символов
   (включая призыв).
3. Призыв — отдельной строкой в конце, через пустую строку:

   `> **Подписывайтесь на [Коты, кошки и котята](https://max.ru/channel_catden)** — <фраза>`

   Фразы — из пула 18 вариантов (см. `local/catden-plan.txt`), не повторяются
   в последних 6 постах (окно 6). Реестр — `cta-phrases.json`.

## Тон

- Тёплый, простой, без канцелярита; тексты переработаны из статей Дзена:
  метрики, подписи под картинками и повторные абзацы вычищены при переносе
  (12.11.2026).
- Без политики, шока, жестокости; медицинские советы — только в формате
  «обратитесь к ветеринару».
- Ссылки в посте — только CTA на сам канал.

## Техника

- Публикация: `publish_post.py` поддерживает и `image_file`, и альбом
  `image_files` (список через « | », до 6 картинок; тест мультивложений MAX —
  12.11.2026, 2 вложения, GET-контроль пройден).
- Медиа лежат в `nev/posting/images/` (в git, ~32 МБ) — пути в `image_file(s)`
  указывают туда; дублировать в папку канала не нужно.
- 6 постов текстовые без картинок (002, 010-p2, 017, 018, 065, 076) —
  публикуются без вложений.
- Правка опубликованного поста: `PUT /messages?message_id=<mid>` с телом
  `{"text": <новый текст>, "format": "markdown"}` (метода PATCH в API нет!).
  Вложения сохраняются, ссылка и message_id не меняются. Порядок (по образцу
  `local/alert_emoji.py`): правка файла поста → сверка текста файла с GET
  /messages/{mid} → PUT → GET-контроль → коммит. Образец:
  `py local/alert_emoji.py`. Правка CTA при опечатках: призыв не меняем.
- Правки пакетные: `ensure_cta_quote.py --channel catden`.
- Перед публикацией вручную: `git pull --rebase origin main`, дерево чистое.
