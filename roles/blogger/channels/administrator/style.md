# Стиль канала «Каналы в MAX: рост и автопилот» (administrator)

Канал: https://max.ru/channel_administrator

Творческая зона (AGENTS.md §0.11): первый абзац и хвост пишутся свободно; при `tail_mode: free` во front matter набор и порядок элементов хвоста (подписка/реакция/вопрос) произвольные.

## База

Общие правила формата — `AGENTS.md` §0 FORMAT CORE v1. Ниже — только дельты
канала. `format_profile: core`, новым постам ставится `format_core: 1`.

1. CTA: чередование `self` ↔ `ainow` через `cta_target: self | ainow` во front
   matter; без поля — `self` + предупреждение владельцу.
2. Перелинковка: 0–1 ссылка на прошлый пост `ainow`, внутри абзаца.
3. Реакции — по общему реестру, ≤ 1 строки, минимум 2 поста между.
4. Объём: ≤ 4000 жёстко, **ориентир 900–1500 знаков**.

## Позиционирование

Авторы и администраторы каналов в MAX, малый бизнес, который ведёт канал сам.
Показываем на своих четырёх каналах, что реально работает в MAX — с цифрами,
а не с советами из интернета. Отличие от `ainow`: там нейросети, здесь —
ведение канала: форматы, метрики, автоматизация, услуги.

## Рубрики

| Рубрика | Когда | Источник |
| --- | --- | --- |
| **Цифра недели** | вторник 09:00 | `roles/blogger/tools/admin_digest_build.py`, stats-JSON |
| **Что мы починили** | четверг 09:00 | git-история репозитория |
| **Приём** | раз в две недели | `docs/methodology/` |

Время задаётся полем `publish_time: 09:00` во front matter; день определяет
рубрика и дата файла. Один пост = одна мысль, 900–1500 знаков.

## Изображения

- «Цифра недели» — карточка с цифрой (`local/admin/`), генерация разрешена.
- Остальные — кадр из архива AI через `roles/blogger/tools/pick_image.py --channel administrator`.
- Прочие изображения — только от владельца.

## Что нельзя

Чужие новости и подборки (уже есть в `ainow` и `na100`); советы без нашей
практики; ежедневный ритм; закреп без прямого разрешения владельца
(`AGENTS.md` §5г). Полная стратегия — `docs/methodology/admin-channel-strategy.md`.
