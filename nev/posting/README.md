## Правила сборки

- один пост — не более 4000 символов (фактический максимум текста 3885);
- длинные статьи режутся на логически законченные части по секциям (заголовок породы/раздела начинает новую часть, если не влезает);
- в посте одна картинка; остальные рисунки статьи идут следующим постом-альбомом с `related_to` — то есть помечены как связанные;
- из текста убраны метрики (просмотры, дочитывания, дата), «статья переезжает», ссылки, призывы и прочий мусор;
- дубли подписей под картинками удалены.

## Как публиковать

```powershell
$env:MAX_HTTP='python'
$env:MAX_CA_CERT=(Resolve-Path local/russian_ca_bundle.pem).Path
py roles/blogger/tools/publish_post.py --channel <slug> <файл поста>
```

`channel` в front matter сейчас `cats` — заглушка: заменить на slug нового канала, когда он появится, и перенести посты в `roles/blogger/channels/<slug>/posts/`.
